# Примеры промтов

## Пример промта для генерации проекта на Go

```plaintext
Создай REST API на языке Go, который подключается к базе данных PostgreSQL.
Добавь следующие эндпоинты:
- GET /users: Получение списка пользователей.
- POST /users: Создание нового пользователя.
- GET /users/{id}: Получение информации о конкретном пользователе по id.
- PUT /users/{id}: Обновление данных пользователя по id.
- DELETE /users/{id}: Удаление пользователя по id.

Добавь поддержку Swagger для генерации документации API. Убедись, что все эндпоинты корректно описаны в Swagger.

Используй стандартный пакет для работы с HTTP, Gorilla Mux для маршрутизации и GORM для взаимодействия с PostgreSQL.
```

## Пример промта для генерации проекта на C#

```plaintext
Надо создать сервис, который хранит информацию по людям, кто сколько хранит яблок. Надо сгенерировать несколько людей и какое-то рандомное кол-во у них яблок. Так же пусть можно будет задавать по апи скаолько у каждого человка яблок. И добавлять новых людей.
Это api сервис, данные он должен отдавать по rest api.
Добавь сваггер.
Язык - сишарп, 8 framework, база постгрес.
Сгенерируй докеркомпоуз для базы. Порт используй 5444
Не забудь создать sql скрипты для инициализации базы и добавить в инит папку в докеркомпозе
Проверь что проект компилируется.
Проверь что запускается
Потом запусти его в докеркомпоузеру и проверь что все ручки работают.
Не забывай, что у тебя всегда есть доступ к файлам
Приложение запускай в докере.
Твоя задача предоставить рабочее приложение.
```

## Пример для morix

```text
Задача: Реализовать поддержку флага -w для управления параметром wait_for_enter. При установленном флаге -w программа должна ожидать нажатия Enter перед выполнением любой команды в функции
run_console_command.

Требования:

 1 Изменить функциональность так, чтобы флаг -w корректно устанавливал параметр wait_for_enter.
 2 Убедиться, что выполнение функции run_console_command зависит от этого параметра.
 3 Обновить конфигурации, чтобы параметр wait_for_enter корректно учитывался.

Ожидаемый результат:

 • При запуске программы с параметром -w перед выполнением любой команды должна быть пауза до нажатия Enter.
 • Код должен быть структурирован так, чтобы изменения легко поддерживались и тестировались в дальнейшем.
```
