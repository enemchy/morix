# Руководство по использованию ignore_pattern_files

Параметр `ignore_pattern_files` в Morix предназначен для управления списком файлов и шаблонов, которые следует игнорировать при сканировании директории. Это позволяет исключать из обработки ненужные файлы или файлы, которые могут повлиять на результаты анализа.

## Что такое ignore_pattern_files?

`ignore_pattern_files` — это список путей к файлам, содержащим шаблоны игнорирования. Эти файлы содержат паттерны, которые используются для фильтрации файлов и папок в процессе сканирования. Например, это могут быть `.gitignore` файлы или другие подобные файлы с описанием масок для игнорирования.

## Почему это важно?

1. **Стоимость**: в первую очередь исключение файлов поможет снизить кол-во используемых токеенов, а это в свою очередь вляет на стоимость.

2. **Скорость и эффективность**: исключение ненужных файлов из сканирования ускоряет процесс анализа.

3. **Чистота данных**: игнорирование временных и служебных файлов снижает шум в данных и позволяет сосредоточиться на анализе полезной информации.

## Как использовать ignore_pattern_files?

1. **Определение файлов для игнорирования**:
   - Добавьте пути к вашим конфигурационным файлам игнорирования в поле `ignore_pattern_files` в `config.yml`. Например:

     ```yaml
     scan:
       ignore_pattern_files:
       - ~/.gitignore_global
       - .gitignore
       - .gptignore
     ```

2. **Создание и редактирование файлов паттернов**:
   - В каждом файле, указанном в `ignore_pattern_files`, можно прописать паттерны игнорирования, например:

     ```text
     *.log
     __pycache__/
     *.tmp
     ```

   - Эти паттерны будут использоваться для исключения соответствующих файлов и папок из результатов сканирования.

3. **Влияние на сканирование**:
   - При запуске Morix, будут учитываться только те файлы и папки, которые не подпадают под паттерны игнорирования, что позволяет фокусироваться на нужных данных.

Используя `ignore_pattern_files`, вы можете снизить кол-во токенов используемых в диалоге с openai.
