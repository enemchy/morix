# Документация по файлу config.yml

Файл `config.yml` используется для настройки работы инструмента Morix. В этом файле определены основные параметры для работы с языковыми моделями, сканирования директорий и выполнения консольных команд.

## Разделы файла конфигурации

### 1. LLM

Параметры, связанные с подключением к языковым моделям.

- **deepseek**:
  - **name**: `deepseek-chat`
  - **base_url**: `https://api.deepseek.com`
  - **token**: Переменная окружения `DEEPSEEK_API_KEY`

- **openai**:
  - **name**: `o3-mini`
  - **base_url**: `https://api.openai.com/v1`
  - **token**: Переменная окружения `OPENAI_API_KEY`

Выбор модели осуществляется в зависимости от параметра, переданного в командной строке (`--llm`, если не задано - используется `openai`).

### 2. Scan

Параметры, связанные с процессом сканирования файлов и директорий:

- **ignore_pattern_files**:
  - Список файлов, содержащих шаблоны для игнорирования. В этот список входят:
    - `~/.gitignore_global`
    - `~/.config/morix/.gptignore`
    - `.gitignore` (файл, расположенный в директории сканирования)
    - `.gptignore` (файл, расположенный в директории сканирования)

- **text_extensions**:
  - Массив расширений файлов, которые автоматически считаются текстовыми. В список входят:
    - `.txt`, `.csv`, `.html`, `.htm`, `.json`, `.xml`, `.py`, `.md`, `.proto`, `.cs`

### 3. Console Commands

Параметры, управляющие выполнением консольных команд:

- **max_output_lines**: `100`
  - Максимальное количество строк вывода, которое будет передано в процесс обработки.

- **allow_run**: `true`
  - Разрешает выполнение команд оболочки из приложения.

- **wait_enter_before_run**: `false`
  - Определяет, будет ли приложение ожидать нажатия клавиши Enter перед выполнением консольной команды.

## Итог

Этот файл конфигурации позволяет настраивать работу инструмента, задавая параметры для взаимодействия с LLM, сканирования директорий (с учетом игнорирования определенных файлов) и выполнения консольных команд с контролем вывода и задержкой, если это необходимо.

Для изменения настроек достаточно отредактировать данный файл и перезапустить приложение.
